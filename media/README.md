# Original Nabeeh media

The files in bundle/ are first-party procedural diagrams, synthesized tones, and generated geometric animations. They contain no competitor artwork, music, voices, logos, or question bank material. scripts/create-release-pack.py records how they are made; release-pack.json records MIME types, byte counts and SHA-256 hashes.

These original media assets are first-party Nabeeh content, authorized for use within this platform. All rights reserved; redistribution requires the owner's permission. The codebase's licensing is a separate decision. No external content rights are implied.

The Arabic question drafts still require editorial approval. The application authorizes media access only for an opened game question owned by the requesting profile. This directory is not a publicly served frontend directory.

User-uploaded media requires a configured S3-compatible object store, credit, license, and optional source. Uploading a file is not a declaration that its question has been verified.
